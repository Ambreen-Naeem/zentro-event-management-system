# Zentro Event Management System

Zentro is a Django-based web application designed for event management, ticket registration, and organizer control. The platform allows users to browse events, register for tickets, and manage event participation efficiently.

## Features

### User Features
- User registration and login
- Browse available events
- Register for events
- View purchased tickets
- Ticket payment system

### Organizer Features
- Create events
- Edit event details
- Cancel or delete events
- View attendee registrations
- Organizer dashboard

## Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/zentro-event-management-system.git
```

### 2. Open Project Folder

```bash
cd zentro-event-management-system
```

### 3. Install Dependencies

```bash
pip install django
```

### 4. Run Server

```bash
python manage.py runserver
```

### 5. Open Browser

```text
http://127.0.0.1:8000/
```
